# Antigravity App 汉化工具

适用于 Windows x64 的离线简体中文汉化工具，支持自动检测安装、备份和恢复。

[下载安装包](https://github.com/yexi-by/AntigravityChinese-OpenSource/releases)，解压后运行 `AntigravityChinese.exe`。

## 使用

1. 完全退出 Antigravity App。
2. 打开汉化工具，核对安装目录，点击“开始汉化”。
3. 完成后重新打开 App。
4. 需要撤销时，退出 App，再点击“恢复原版”。

官方更新覆盖汉化后，重新运行一次本工具即可。

## 说明

- 当前适配 Antigravity App 2.28.2，未识别的新文案保留原文。
- 仅修改界面显示，用户内容、代码和模型名称保持原样。
- 备份保存在 `%LOCALAPPDATA%\AntigravityChinese\backups`，请保留以便恢复。
- 工具按需运行，没有常驻进程。
