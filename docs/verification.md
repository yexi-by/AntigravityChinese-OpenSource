# v0.1.1 验证记录

2026-10-19，在 Windows x64 上以 Antigravity App 2.24.0 为基线完成验证。安装及恢复先使用验证副本；本轮根据“模型与用量”页的实机反馈修复后，再更新本机日常安装。

内置包有 3,297 条有效译文；安装记录统计 3,665 个已匹配文案项（含动态显示的候选模板），72 项保留原文。同一译文可以用于多个位置；这些数量只描述已识别范围，不代表界面覆盖率。

## 自动检查

Release 构建通过，零警告、零错误。`dotnet run --project tests/AntigravityChinese.Checks -c Release --no-restore` 的八组行为检查通过：

| 跨构建复用 | 文件名、偏移和显示写法变化后复用语境适用的译文；歧义及未知文案保留原文 |

| 安装与更新 | 模拟未知版本 99.99 可安装、重复应用和恢复；单独更新服务时重新绑定资源；部分结构不支持时保留对应原版资源 |

| 原生入口 | 保留 WSL 行为；即使服务大小和时间戳不变，摘要变化也不会继续加载旧中文 ZIP |

八组测试涵盖上表多个相关场景，不等于八次完整 App 功能验收。

## 真实服务与界面

使用 `scripts/verify-bundle.mjs` 启动原版 `language_server.exe`，通过其原生 `--web_bundle_path` 入口读取生成资源，确认：

- 首页引用带内容标记的脚本地址，实际返回的 JavaScript 与中文 ZIP 中字节一致，包含中文译文。
- 样式文件保持原始字节，配置 RPC `GetServerConfiguration` 返回 HTTP 200。
- 最终主脚本为 10,121,270 字节，SHA-256 为 `135389653d82090c51aa252f52838580232e900085343ea6028844ca10357edf`。

在实际 Electron 验证副本中观察了启动后的主界面、文件菜单、常规设置、外观设置和模型用量页，并确认页面切换后中文继续显示。新对话、侧边栏、输入提示、设置导航和主要设置说明已显示中文；模型和产品名称保持英文。外观页代码预览中的 `name`、`${name}` 及注释保持原文，未被普通界面词替换。

本轮在验证副本及更新后的本机日常安装中实测确认：“Gemini 模型”“Claude 和 GPT 模型”“本周剩余额度”“5 小时剩余额度”“Gemini 4 Argon 每周额度”、升级说明和“6 天 19 小时后完全恢复”均显示中文；Google AI Pro、Google AI Ultra 和型号保持原样，百分比仍为接口返回值。没有操作 AI 点数超额使用开关、升级链接或模型请求。

验证副本在所有模块加载前隔离文件目录，关闭副本更新检查。为绕过首次隐私引导，仅在副本状态中预置 `agent_onboarding_completed: 2`，没有操作遥测同意开关。系统登录服务仍复用了现有登录状态；这次没有主动登录、发送对话、修改账户或安全设置。含账户信息的截图未纳入仓库或分发包。

早期副本隔离时序问题曾触发上游 IDE 迁移，修正后不再触发；核对创建时间后，将该次新增的 `.gemini/antigravity-ide` 和 `.gemini/antigravity-backup` 移入回收站，已确认原位置不存在。原有目录保留。

## 维护、还原与分发

旧提取器的静态检查没有涵盖这些服务端文案；本轮依据截图追溯到配额及套餐显示消费者，新增七组语境，经 ATT Extract 保留原 3,339 条正文，再通过 Manual 复用或补译 27 个单元并 WriteBack。导入后 Check 返回零新增语境、零待补译、零结构提示。本轮未请求翻译模型。静态检查仅适用于已登记的模板和已识别的显示范围，不能替代服务端新文案的实机反馈。

ATT 导出包含 3,366 个历史及当前翻译单元。静态 QA 的确认问题为零，仍有 160 条启发式提示、四组复核项，与上轮相同，涉及名称、路径、代码、术语及片段；QA 总状态仍为 `needs_review`，不能据此宣称全面验收通过。逐单元的外部源映射、逆向转换及完整布局报告尚未生成；上述服务和界面验证单独记录。

结束副本验证后只停止了本项目副本的进程，并执行恢复。恢复后的 EXE、ASAR 摘要均与该副本汉化前原件相同，自有中文 ZIP 已移除。更新日常安装时先正常关闭 App，保留原始备份，再应用当前包并核对写入摘要；服务文件保持原样。

发布的 Windows x64 自包含程序内置 3,297 条译文。ZIP 仅包含本工具、使用说明和许可证，`release/` 另有 `SHA256SUMS.txt`。ATT 配置、密钥、原版程序和验证账户数据均不打包。

## 当前限制

仍有部分固定标签和提示保留英文，包括 `No Project`、`Execution`、`Chat Settings`、`Create Project`、部分策略和主题名称、无障碍提示。尚未登记的服务端句式、公告和部分引导内容也保持原文。这些位置是后续覆盖维护的候选，不能算作已完成汉化。

WSL 后端保留原版主界面。模型请求、远程连接、终端操作、所有设置保存及上游自动更新未逐项实机验收；新版本的兼容行为已有模拟检查，但仍需按维护说明检查真实新版本。当前结果支持本版本已验证范围的使用，不承诺所有版本、所有功能均已实测。
