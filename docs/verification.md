# v0.1.5 验证记录

2026-10-20，在 Windows x64 上以 Antigravity App 2.24.0 为基线验证资源加载修复。本版沿用 v0.1.4 的译文，修复文件图标、图片及其他子目录资源被首页 HTML 替代的问题，并补充全资源 HTTP 检查。既有菜单和设置页面的验证结果在下文注明，不视为本轮重新逐页验收。

内置包有 3,853 条有效译文；安装记录统计 4,133 个已匹配文案项（含动态显示的候选模板），123 项保留原文。同一译文可以用于多个位置；这些数量只描述已识别范围，不代表界面覆盖率。

## 真实服务与界面

对照原生内嵌资源、未经修改的原版外部 ZIP、中文外部 ZIP 和中文资源目录：两个外部 ZIP 均出现子目录请求回退首页的现象，排除了译文、图片字节和 ZIP 目录属性的影响；目录入口正常。

使用 `scripts/verify-bundle.mjs` 启动原版 `language_server.exe`，通过其原生 `--web_bundle_path` 目录入口验证隔离副本及重新应用后的本机安装，确认：

- 首页引用带内容标记的脚本地址，实际返回的 JavaScript 与中文 ZIP 中字节一致，包含中文译文。
- 全部 298 个静态资源返回字节与中文 ZIP 一致：283 个 SVG、3 个 PNG、2 个 MP3、2 个 CSS、4 个 JS、3 个 MJS 和 1 个 JSON。包含文件类型、文件夹、图标主题和 PDF worker 资源；没有返回首页冒充资源的情况。
- 原版与目录入口的资源 MIME 类型逐类一致；图片和样式另有 MIME 断言。当前资源包没有字体文件。配置 RPC `GetServerConfiguration` 返回 HTTP 200。
- 当前译文生成的主脚本为 10,148,016 字节，SHA-256 为 `ffe0ff1270f7b75a9d953099d49da196637d874dd71630a4ca69865ba227c21e`。

本机 App 正常退出后，从已有备份准备并应用 v0.1.5，随后重新启动。实际对话的多条 `Analyzed` 文件引用已显示 Markdown 图标，打开文件后，预览标签和路径中的图标也正常显示。此前同一文件标签显示破图。检查过程仅展开已有工具活动、打开文件预览，没有发送模型请求或修改用户文件；含对话内容的截图没有保存到仓库或分发包。

PDF worker 已验证资源内容和 MIME 与原版一致；本轮没有实际打开 PDF 验收渲染效果。远端网页及用户附件不属于此次内置资源包检查范围。

## 维护、还原与分发

共享下拉组件的显示解析函数与预设元数据曾被旧提取器遗漏，现已补充最终显示消费者，并经 ATT 增量提取、复用和 Manual 审校维护。当前 Check 返回零新增语境、零待补译、零结构提示；最近的 ATT Pending 和 Rejected 均为零。最近两轮补译和语义修订均未请求翻译模型。静态检查仅适用于已登记的模板和已识别的显示范围，不能替代服务端新文案的实机反馈。

ATT 导出包含 3,963 个历史及当前翻译单元。静态 QA 的确认问题为零，仍有 212 条启发式提示、四组复核项，涉及名称、路径、代码、术语及片段；新增提示来自保留的 Fig、JJ、Piper、Cog、Project 4K 等名称在新语境中的重复出现。QA 总状态仍为 `needs_review`。逐单元的外部源映射、逆向转换及完整布局报告尚未生成；上述服务和界面验证单独记录。

结束副本验证后只停止了本项目副本的进程，并执行恢复。恢复后的 EXE、ASAR 摘要均与该副本汉化前原件相同，自有中文 ZIP 已移除。更新日常安装时先正常关闭 App，保留原始备份，再应用当前包并核对写入摘要；服务文件保持原样。

发布的 Windows x64 自包含程序内置 3,853 条译文。ZIP 仅包含本工具、使用说明和许可证，`release/` 另有 `SHA256SUMS.txt`。已核对程序版本、ZIP 内文件及摘要，并用分发 EXE 的预览入口确认可启动。ATT 配置、密钥、原版程序和验证账户数据均不打包。公开前已扫描全部提交中的文件版本，未发现本机已配置密钥或私钥，也未纳入 `.local`、构建输出及原版程序。

## 当前限制

仍有部分固定标签和提示保留英文，包括 `Execution`、`Chat Settings`、部分主题名称、无障碍提示。尚未登记的服务端句式、公告和部分引导内容也保持原文。这些位置是后续覆盖维护的候选，不能算作已完成汉化。

WSL 后端保留原版主界面。模型请求、远程连接、终端操作、所有设置保存及上游自动更新未逐项实机验收；新版本的兼容行为已有模拟检查，但仍需按维护说明检查真实新版本。当前结果支持本版本已验证范围的使用，不承诺所有版本、所有功能均已实测。
