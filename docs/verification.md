# v0.1.0 验证记录

2026-10-19，在 Windows x64 上以 Antigravity App 2.24.0 为基线完成验证。安装与恢复使用本机原版的验证副本，日常安装没有应用汉化。

内置包有 3,270 条有效译文；当前基线实际写入 3,629 个显示位置，72 个位置保留原文。同一译文可以用于多个位置；这些数量只描述已识别范围，不代表界面覆盖率。

## 自动检查

`dotnet build AntigravityChinese.slnx -c Release --no-restore` 通过，零警告、零错误。`dotnet run --project tests/AntigravityChinese.Checks -c Release` 的七组行为检查通过：

| 验证对象 | 已确认的行为 |
| --- | --- |
| 显示与内容边界 | 内部字段、动态表达式求值次数和顺序、品牌名称、用户可编辑内容不变；嵌套高亮代码和等宽预格式代码块排除汉化 |
| 跨构建复用 | 文件名、偏移和显示写法变化后复用语境适用的译文；歧义及未知文案保留原文 |
| 设置与路由 | 只转换显示值，保留枚举、命令 ID、快捷键及 `screen` 路由；补充显示名不替换身份值 |
| 安装与更新 | 模拟未知版本 99.99 可安装、重复应用和恢复；单独更新服务时重新绑定资源；部分结构不支持时保留对应原版资源 |
| 失败与恢复 | 文件锁导致写入失败时回滚；旧备份不覆盖不匹配的新安装；遗留的自有中文 ZIP 不阻断新版应用；匹配多个记录时恢复最近原件 |
| 原生入口 | 保留 WSL 行为；即使服务大小和时间戳不变，摘要变化也不会继续加载旧中文 ZIP |

七组测试涵盖上表多个相关场景，不等于七次完整 App 功能验收。

## 真实服务与界面

使用 `scripts/verify-bundle.mjs` 启动原版 `language_server.exe`，通过其原生 `--web_bundle_path` 入口读取生成资源，确认：

- 首页引用带内容标记的脚本地址，实际返回的 JavaScript 与中文 ZIP 中字节一致，包含中文译文。
- 样式文件保持原始字节，配置 RPC `GetServerConfiguration` 返回 HTTP 200。
- 最终主脚本为 10,110,253 字节，SHA-256 为 `ed6ecf23c6f2418777ee1d7ddcd7b9cbad925ba40ca100e057cb4e0025b8c7c1`。

在实际 Electron 验证副本中观察了启动后的主界面、文件菜单、常规设置、外观设置和模型用量页，并确认页面切换后中文继续显示。新对话、侧边栏、输入提示、设置导航和主要设置说明已显示中文；模型和产品名称保持英文。外观页代码预览中的 `name`、`${name}` 及注释保持原文，未被普通界面词替换。

验证副本在所有模块加载前隔离文件目录，关闭副本更新检查。为绕过首次隐私引导，仅在副本状态中预置 `agent_onboarding_completed: 2`，没有操作遥测同意开关。系统登录服务仍复用了现有登录状态；这次没有主动登录、发送对话、修改账户或安全设置。含账户信息的截图未纳入仓库或分发包。

早期副本隔离时序问题曾触发上游 IDE 迁移，修正后不再触发；核对创建时间后，将该次新增的 `.gemini/antigravity-ide` 和 `.gemini/antigravity-backup` 移入回收站，已确认原位置不存在。原有目录保留。

## 维护、还原与分发

当前基线的 `maintain.ps1 -Mode Update -Profile opencode` 返回“无需更新项目”。对比前后翻译资产摘要和 ATT 运行日志，资产未变化，也没有新增 ATT 请求；检查结果为零新增语境、零待补译、零结构提示。这个结论仅适用于提取器已识别的显示范围。

ATT 导出包含 3,339 个历史及当前翻译单元。静态 QA 的确认问题为零，仍有 160 条启发式提示、四组复核项，涉及名称、路径、代码、术语及片段；QA 总状态仍为 `needs_review`，不能据此宣称全面验收通过。逐单元的外部源映射、逆向转换及完整布局报告尚未生成；上述服务和界面验证单独记录。

结束验证后只停止了本项目副本的进程，并执行恢复。恢复后的 EXE、ASAR 摘要均与该副本汉化前原件相同，服务摘要不变，自有中文 ZIP 已移除。另行核对日常安装的 EXE、ASAR 和服务摘要，均与操作前一致。

发布的 Windows x64 自包含程序可直接启动，内置包显示 3,270 条译文。ZIP 内仅含本工具、使用说明和许可证；包内程序与独立 EXE 摘要相同，`SHA256SUMS.txt` 校验通过。ATT 配置、密钥、原版程序和验证账户数据均未打包。

## 当前限制

仍有部分固定标签和提示保留英文，包括 `No Project`、`Execution`、`Chat Settings`、`Create Project`、部分策略和主题名称、无障碍提示，以及模型配额和升级说明。后端下发的公告和部分引导内容也保持原文。这些位置是后续覆盖维护的候选，不能算作已完成汉化。

WSL 后端保留原版主界面。模型请求、远程连接、终端操作、所有设置保存及上游自动更新未逐项实机验收；新版本的兼容行为已有模拟检查，但仍需按维护说明检查真实新版本。当前结果支持本版本已验证范围的使用，不承诺所有版本、所有功能均已实测。
