# v0.1.3 验证记录

2026-10-19，在 Windows x64 上以 Antigravity App 2.24.0 为基线完成验证。本轮根据安全预设、文件访问和计划审核选项及其说明的截图反馈返修，先验证隔离副本，再更新本机日常安装。

内置包有 3,853 条有效译文；安装记录统计 4,133 个已匹配文案项（含动态显示的候选模板），123 项保留原文。同一译文可以用于多个位置；这些数量只描述已识别范围，不代表界面覆盖率。

- 首页引用带内容标记的脚本地址，实际返回的 JavaScript 与中文 ZIP 中字节一致，包含中文译文。
- 样式文件保持原始字节，配置 RPC `GetServerConfiguration` 返回 HTTP 200。
- 最终主脚本为 10,147,609 字节，SHA-256 为 `8c8ab6a228d305e3b358de02007bdb9775ee183fdb9362d01fcc7152614b1468`。

在实际 Electron 验证副本中观察了启动后的主界面、文件菜单、常规设置、外观设置和模型用量页，并确认页面切换后中文继续显示。新对话、侧边栏、输入提示、设置导航和主要设置说明已显示中文；模型和产品名称保持英文。外观页代码预览中的 `name`、`${name}` 及注释保持原文，未被普通界面词替换。

在验证副本及更新后的本机日常安装中实测确认：“Gemini 模型”“Claude 和 GPT 模型”“本周剩余额度”“5 小时剩余额度”“Gemini 4 Argon 每周额度”、升级说明和刷新时长均显示中文；Google AI Pro、Google AI Ultra 和型号保持原样，百分比仍为接口返回值。没有操作 AI 点数超额使用开关、升级链接或模型请求。

已验证文件菜单中的“新建项目”、项目选择器的默认标题“无项目”，以及下拉菜单中的“未找到项目”“新建项目”“快速开始”和说明。模型分组的悬浮提示显示“本组包含的模型：Claude Opus, Claude Sonnet, GPT-OSS”，模型列表保持原样。未点击创建项目或快速开始。

本轮在验证副本中展开安全预设，确认“默认”“整机访问”“极速模式”“自定义”及其简短说明显示中文；“了解更多”中的详细说明正常换行。更新本机安装前后核对了自定义预设、文件访问、终端执行和计划审核的当前选择及沙盒开关，显示文字改变，设置保持原状。仅展开、收起菜单及查看说明，没有选择权限选项或操作开关。

早期副本隔离时序问题曾触发上游 IDE 迁移，修正后不再触发；核对创建时间后，将该次新增的 `.gemini/antigravity-ide` 和 `.gemini/antigravity-backup` 移入回收站，已确认原位置不存在。原有目录保留。

## 维护、还原与分发

旧提取器没有覆盖共享下拉组件的显示解析函数与预设元数据。本轮补充最终显示消费者，提取九组新增语境，经 ATT Extract 保留已有正文，复用已发布译文后，通过 Manual 集中审校 283 个待补单元并 WriteBack。导入后 Check 返回零新增语境、零待补译、零结构提示；ATT Pending 和 Rejected 均为零。本轮未请求翻译模型。静态检查仅适用于已登记的模板和已识别的显示范围，不能替代服务端新文案的实机反馈。

ATT 导出包含 3,963 个历史及当前翻译单元。静态 QA 的确认问题为零，仍有 212 条启发式提示、四组复核项，涉及名称、路径、代码、术语及片段；新增提示来自保留的 Fig、JJ、Piper、Cog、Project 4K 等名称在新语境中的重复出现。QA 总状态仍为 `needs_review`。逐单元的外部源映射、逆向转换及完整布局报告尚未生成；上述服务和界面验证单独记录。

结束副本验证后只停止了本项目副本的进程，并执行恢复。恢复后的 EXE、ASAR 摘要均与该副本汉化前原件相同，自有中文 ZIP 已移除。更新日常安装时先正常关闭 App，保留原始备份，再应用当前包并核对写入摘要；服务文件保持原样。

发布的 Windows x64 自包含程序内置 3,853 条译文。ZIP 仅包含本工具、使用说明和许可证，`release/` 另有 `SHA256SUMS.txt`。ATT 配置、密钥、原版程序和验证账户数据均不打包。

## 当前限制

仍有部分固定标签和提示保留英文，包括 `Execution`、`Chat Settings`、部分主题名称、无障碍提示。尚未登记的服务端句式、公告和部分引导内容也保持原文。这些位置是后续覆盖维护的候选，不能算作已完成汉化。

WSL 后端保留原版主界面。模型请求、远程连接、终端操作、所有设置保存及上游自动更新未逐项实机验收；新版本的兼容行为已有模拟检查，但仍需按维护说明检查真实新版本。当前结果支持本版本已验证范围的使用，不承诺所有版本、所有功能均已实测。
